# leangear-AI

An AI-assisted Nutrition and Diet Analysis Application.

## Objective

leangear-AI helps users understand their daily
food consumption by analysing nutritional information.

## Planned Features

- Food and quantity input,handle uncertain inputs
- Calorie calculation
- Protein calculation
- AI-powered food interpretation
- Daily nutrition reports
- Diet ranking system

## Technologies

- Python
- Git and GitHub
- AI API
- Nutrition Database
